# 조립 중 실측 체크리스트

> 작업대에서 폰으로 보는 용. 줄자·버니어캘리퍼스 준비.
> **🔴 는 커버 덮으면 못 재는 것** — 그 전에 먼저.

---

## 0. 먼저 — 기준점을 정한다

이걸 안 정하면 나중에 "이 3cm가 어디서부터야?" 가 됩니다. **팀원이랑 같이 한 번 합의하고 시작하세요.**

```
base_footprint  = 지면 위, 로봇의 중심
                  · 중심 = 바퀴 축 4개가 만드는 사각형의 한가운데
                  · 높이 = 지면 (0)
                  · X = 로봇 전방, Y = 왼쪽, Z = 위
```

앞으로 나오는 좌표는 **전부 이 점 기준**입니다. 섀시 바닥판이나 프린트물 모서리 기준이 아니에요.

바닥에 십자 표시를 하거나, 바퀴 축 중심 사이에 실을 걸어 교차점을 잡으면 편합니다.

---

## 🔴 커버 덮기 전에

### 1. 라이다 (`lidar_link`)

- [ ] 지면에서 **스캔면까지 높이** (mm) — 케이스 바닥이 아니라 회전하는 스캔 평면
- [ ] base_footprint 기준 앞뒤(x) / 좌우(y) 오프셋 — 정중앙이 아니면 반드시
- [ ] **yaw 각도** — 라이다 0° 방향이 로봇 전방과 몇 도 틀어져 있는지
  - A2M12는 케이스에 방향 표시가 있음. 케이블 나오는 쪽 기준으로 재도 됨
  - 이거 틀리면 지도 전체가 그만큼 돌아갑니다

### 2. IMU (`imu_link`)

- [ ] base_footprint 기준 x / y / z
- [ ] **어느 방향으로 붙었는지** — 보드의 X축 화살표가 로봇 전방을 보는지
  - 90° 돌아가 있으면 yaw가 그만큼 틀어짐. 뒤집혀 있으면 부호가 반대
  - 📷 **사진 찍어두세요.** 나중에 부호가 이상할 때 이 사진 하나로 해결됩니다
- [ ] 모터 드라이버·배터리 케이블에서 떨어뜨렸는지 (지자기 센서라 자기장에 흔들림)

### 3. 카메라 (`camera_link`)

- [ ] **리프트 상판 기준** x / y / z — base_footprint가 아니라 리프트 상판 기준
- [ ] **아래로 기운 각도(틸트)** — 15~30° 범위로 고정하기로 했음
  - 각도기 없으면 옆에서 사진 찍어서 나중에 재도 됨

### 4. 리프트

- [ ] **완전히 접혔을 때** 지면에서 리프트 상판까지 높이 (mm)
  - 이게 `lift_mm` 기준면 결정에 직결됨
- [ ] **완전히 올렸을 때** 높이 (mm)
- [ ] 가동 범위가 100~740mm 맞는지

### 5. 배선

- [ ] 📷 **전체 배선 사진** — 위/앞/뒤 각 한 장
- [ ] USB 어느 장치가 허브 몇 번 구멍에 꽂혔는지 (라벨 붙이면 더 좋음)
- [ ] 카메라 USB 케이블이 리프트 상하 이동을 따라갈 여유가 있는지 (100~740mm)

---

## 🟡 조립 끝난 뒤 (아무 때나)

### 6. 바퀴

- [ ] **트랙폭** — 좌우 바퀴 **축 중심** 간 거리 (바깥면 아님)
- [ ] **휠베이스** — 앞뒤 바퀴 축 중심 간 거리
- [ ] 로봇을 내려놓은 상태에서 **지면~바퀴 축 중심 높이** = 하중 걸린 유효 반경
  - CAD 외경 80.29mm는 눌리기 전 값. 실제로는 좀 작아짐

### 7. 외곽 치수 (footprint용)

바퀴·범퍼·튀어나온 부품 전부 포함한 **제일 바깥** 기준.

- [ ] 펼침 상태 가로 × 세로
- [ ] 축소 상태 가로 × 세로

> 지금 코드에 문서값(394×492)과 다른 값(451×499)이 섞여 있어서, 실측으로 확정하면 정리됩니다.

## 재고 나서

숫자만 여기 붙여서 주시면 제가 URDF·config에 반영하고 커밋할게요.

```
라이다   높이 ___mm   x ___mm   y ___mm   yaw ___°
IMU      x ___mm   y ___mm   z ___mm   방향: 전방/좌90/우90/반대
카메라   리프트상판 기준  x ___mm  y ___mm  z ___mm   틸트 ___°
리프트   접힘 ___mm   최대 ___mm
바퀴     트랙폭 ___mm   휠베이스 ___mm   축높이 ___mm
외곽     펼침 ___ × ___mm    축소 ___ × ___mm
```

## 팁

**mm 단위로 적으세요.** 코드는 m를 쓰지만 변환은 제가 합니다. 재는 사람이 단위 변환하면 실수가 나요.

**애매하면 사진.** 각도나 방향은 말로 적기 어려워요. 옆에서 찍은 사진 한 장이 훨씬 정확합니다.

**대충이라도 적어두세요.** "나중에 다시 재지" 하면 커버가 덮여 있습니다. ±5mm라도 적어두면 나중에 보정할 기준이 생겨요.
