## 1. 🔴 3D 프린트 발주 전에 확정할 것 (마감: 프린트 발주일)

이 섹션은 **프린트가 시작되면 되돌릴 수 없음**. 다른 어떤 작업보다 먼저.

### 1-1. 섀시팀에서 받아야 할 값

- [ ] **STEP(또는 STL) 파일 확보** ★ 최우선 — 렌더 이미지로는 판단 불가. 받으면 아래 치수 대부분을 FreeCAD로 직접 실측 가능하므로 왕복 질문이 줄어듦
- [ ] 수정된 CAD 기준 **트랙폭 / 휠베이스** (바퀴 축 중심 간 실측치)
  - 기존 사용값: 트랙폭 250mm(스펙) vs 244.4mm(FreeCAD 실측), 휠베이스 186mm → 변경 여부 확인
- [ ] **가변폭 범위** 재확인 (기존: 가로 280~394mm / 세로 378~492mm)
  - 7/27 확인: **대각선 45° 수축**. 가로 394→280, 세로 492→378로 델타가 둘 다 114mm로 동일 → 모서리 하나가 x·y 각각 57mm, 대각선 약 81mm 이동
- [ ] **Nav2 footprint 재확정** (기존 0.394 × 0.492m) — 폭이 바뀌면 costmap·Collision Monitor 폴리곤 전부 영향
- [ ] **3D 프린트 완료 예정일** — 8/8 역산의 기준점
- [ ] 섀시 대략 질량 (URDF inertia 근사용)

### 1-2. LiDAR 마운트 — 7/27 갱신 ✅ 큰 방향 확정

**해소됨**: 라이다 **전용 고정 구조물**을 두기로 확정. 가변폭 브래킷과 분리되므로 `base_link → lidar_link`가 상수로 유지됨.

파생 효과 세 가지 — Dynamic TF로 폭을 보상할 필요가 없어졌고, **ESP32 #2가 비블로킹 상태 그대로 유지**되며(로컬라이제이션이 섀시폭 데이터에 묶이지 않음), **Slamtec C1 전환 검토가 불필요**해짐.

> 만약 라이다가 가변폭 브래킷에 붙었다면 대각선 수축으로 주행 중 약 81mm 이동했을 것. 1.2m 복도에서 8cm면 AMCL이 흔들리고, 하필 폭을 줄이는 순간(= 가장 좁은 곳)에 가장 크게 틀어졌을 구조. **이 판단은 심사에서 설명할 가치가 있음.**

**남은 결정은 사실상 "높이" 하나.**

- [ ] **구조물 높이 확정** — 기준: **최소폭 상태**에서 네 모서리 브래킷보다 스캔면이 위일 것
  - 대각선 수축이라 폭을 줄이면 브래킷이 라이다 쪽으로 x·y 각각 57mm씩 접근. **최대폭 기준으로 정하면 폭을 줄였을 때 전방 대각선 4방향에 사각지대**가 생김 — 제일 안 좋은 자리
- [ ] **높이 상한 검토** — 25~30cm 초과 시 재검토 (기존 명세서 값: 지면 기준 17.5cm)
  - 2D 라이다는 한 평면만 봄 → 너무 높으면 문턱·사람 발·휠체어 발판 같은 저상 장애물을 전부 놓침. 케어시설에서는 실질 위험 요소
- [ ] **강성·진동 요구 전달** — 짧고 굵게 + 보강 리브
  - 메카넘 롤러 주행 진동 + 라이다 자체 600rpm 불균형 → 얇고 긴 기둥은 공진 → 스캔 흔들림이 scan matching 품질로 직결. 3D 프린트라 특히 취약
- [ ] **마운트 나사 제한 전달** — 바닥 M3 4개, **길이 4mm 초과 금지**
  - 초과 시 내부 모듈 손상 (데이터시트 명시 경고). 플레이트 두께 설계에 직결
- [ ] 아래에서 받치는 형태 유지 확인 — 스캔면 주변에 지지 기둥이 없어야 함 (현재 방향 맞음)
- [ ] 라이다 케이블이 구조물 타고 내려가는 경로 확보
- [ ] **STEP 확보 후 직접 검증** — 스캔면 높이로 단면을 잘라 바퀴 브래킷·후방 곡면 커버·리프트 베이스의 간섭 각도 측정 (최소폭·최대폭 두 상태 모두)

### 1-3. 나머지 센서 장착 요건

- [ ] **BNO055 IMU**: 모터 드라이버·배터리 케이블에서 최대한 이격 (지자기 센서 내장 → yaw 흔들림). REP-103 방향(X=전방, Y=좌, Z=상)
- [ ] **D415 카메라**: 리프트 상단, 아래로 **15~30° 고정 틸트** (조절식 비채택 — TF 변수 증가)
- [ ] **USB-C 케이블 배선**: 리프트 100~740mm 상하 이동 추종. 여유 길이 + 케이블 체인 경로. 짧으면 탈락, 길면 기구 간섭
- [ ] **센서 좌표 실측용 기준면 정의**: 조립 후 `lidar_link` / `imu_link` / `lift_top → camera_link`(xyz + 틸트각)를 줄자로 잴 수 있게 기준점 합의
- [ ] USB 허브·젯슨·배터리 배치 공간 확보 (허브 4포트 + 케이블 5가닥)

### 1-4. 지연 대비

- [ ] **플랜 B**: 3D 프린트가 8/5을 넘기면 → 아크릴판/알루미늄 프로파일 임시 섀시에 바퀴+라이다만 얹어 **주행·SLAM 검증만이라도** 선행. 리프트·가변폭은 최종 섀시로
- [ ] 프린트 실패(휨/치수 오차) 대비 여유일 1~2일 확보
